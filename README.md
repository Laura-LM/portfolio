# Portfolio

A personal portfolio website that highlights my experience, technical skills, and featured projects as a Full-Stack Web Developer.

## Overview

This portfolio was built to present my professional profile in a clear and modern way, including:

- About me
- Work experience
- Technical skills
- Project showcase with GitHub and live demo links

## Features

- Responsive design for desktop and mobile
- Clean UI with a dark theme
- Project cards with screenshots and links
- Lightbox-style image viewer for project images
- Sticky navigation for quick section access

## Built With

- HTML5
- CSS3
- JavaScript (ES6+)

## Portfolio Sections

- **Hero**: Name and professional title
- **About Me**: Background, education, languages, and certifications
- **Experience**: Professional experience and responsibilities
- **Skills**: Frontend, backend, tools, and cybersecurity knowledge
- **Projects**: Selected development work
